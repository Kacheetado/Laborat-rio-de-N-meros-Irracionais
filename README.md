
O Laboratório de Números Irracionais é produto do projeto de pesquisa do IFPB/CG chamado "Realmente conhecemos os números irracionais? Uma abordagem para identificá-los usando ferramentas do ensino básico", seus membros são Kauã Fabson, Maria Alice Éllysson Emanuel e Jonathas Jerônimo.
O objetivo do projeto é estudar números irracionais utilizando as ferramentas do ensino básico, mesmo que não se limite apenas a isso, e utilizar dessas ferramentas para obter infinitos números irracionais.
Na versão inicial da ferramenta, existem as seguintes funcionalidades:
- Aba inicial focada em utilizar o teorema fundamental da aritmética para determinar se uma raiz de índice N de um número natural maior ou igual a 2 é irracional ou racional.
- Aba dedicada a solucionar polinômios e determinar se suas raízes são racionais ou racionais, através do teorema das raízes racionais (TRR).
- Aba com uma tabela contendo alguns números irracionais notáveis
- Última aba com um pouco da história dos números irracionais 

Update 1.0.1
O que há de novo? 
Quatro novas abas repletas de funcionalidades.
Primeira aba adicionada:
- Funções trigonometricas. Agora é possivel obter os valores dos angulos do seno, cosseno e tangente em decimal. Além, claro, de obter a informação se o número é irracional ou não.
Segunda aba adicionada:
- Critério de Irredutibilidade de Eisenstein. Utilizando o método de decomposição de polinômios em conjunto com o TRR
Terceira aba adicionada:
- Reconhecimento Construtivo via Frações Contínuas Simples. Através de frações contínuas o algoritmo retorna se a raiz do número natural é irracional ou não - além de gerar suas melhores aproximações racionais em fração e decimal.
